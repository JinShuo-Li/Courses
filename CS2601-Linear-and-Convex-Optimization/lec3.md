# Lecture 3 Convex Sets and Functions

## Convex Sets

### Lines, line segments, and rays

Given two points $x_1, x_2 \in \mathbb{R}^n$, the line through these points is defined as the set of all points of the form:
$$
\{x \in \mathbb{R}^n : x = \alpha x_1 + (1 - \alpha) x_2 = x_2 + \alpha (x_1 - x_2), \alpha \in \mathbb{R}\}.
$$

The line segment between $x_1$ and $x_2$ is defined as the set of all points of the form:
$$
\{x \in \mathbb{R}^n : x = \alpha x_1 + (1 - \alpha) x_2 = x_2 + \alpha (x_1 - x_2), \alpha \in [0, 1]\}.
$$

The ray starting at $x_1$ and passing through $x_2$ is defined as the set of all points of the form:
$$
\{x \in \mathbb{R}^n : x = \alpha x_1 + (1 - \alpha) x_2 = x_2 + \alpha (x_1 - x_2), \alpha \in [0, \infty)\}.
$$

### Convex sets

A set $C \subseteq \mathbb{R}^n$ is convex if for any two points $x_1, x_2 \in C$, the line segment between them lies entirely within $C$. Formally, this means that for all $\alpha \in [0, 1]$:

$$
x_1 \in C, x_2 \in C \implies \alpha x_1 + \overline{\alpha} x_2 \in C.
$$

*Note*: For $\alpha \in [0, 1]$, we have $\overline{\alpha} = 1 - \alpha$. And $\alpha x + \overline{\alpha} y$ is called a convex combination of $x$ and $y$.

Examples of convex sets include:

- Empty set $\emptyset$
- A hyperplane $\{x \in \mathbb{R}^n : a^T x = b\}$ for some $a \in \mathbb{R}^n, b \in \mathbb{R}$

*Proof*: Let $x_1, x_2 \in \{x \in \mathbb{R}^n : a^T x = b\}$. Then $a^T x_1 = b$ and $a^T x_2 = b$. For any $\alpha \in [0, 1]$, we have:

$$
a^T (\alpha x_1 + \overline{\alpha} x_2) = \alpha a^T x_1 + \overline{\alpha} a^T x_2 = \alpha b + \overline{\alpha} b = b.
$$

**Proposition**: The intersection of any collection of convex sets is convex. (Set intersection preserves convexity.)

*Proof*: Let $\{C_i\}_{i \in I}$ be a collection of convex sets, and let $C = \bigcap_{i \in I} C_i$. Take any two points $x_1, x_2 \in C$. Since $x_1, x_2 \in C$, it follows that $x_1, x_2 \in C_i$ for all $i \in I$. By the definition of convexity, for any $\alpha \in [0, 1]$, we have:

$$
\alpha x_1 + \overline{\alpha} x_2 \in C_i \quad \forall i \in I.
$$

Therefore, $\alpha x_1 + \overline{\alpha} x_2 \in C$, which proves that $C$ is convex.

Affine spaces are also convex.

### Convex combination

A convex combination of $x_1, x_2, \cdots, x_m$ is a point of the form:

$$
\sum_{i=1}^m \theta_i x_i \quad \text{where} \quad \theta_i \geq 0, \sum_{i=1}^m \theta_i = 1.
$$

**Theorem**: If $C$ is a convex set, then any convex combination of points $\sum_{i=1}^m \theta_i x_i$ in $C$ also lies in $C$.

### Convex hull

The convex hull of a set $S \subset \mathbb{R}^n$, denoted as $\text{conv}(S)$, is the smallest convex set containing $S$.

**Theorem**: The convex hull $\text{conv}(S)$ is the set of all convex combinations of points in $S$.

### Affinely independent points

$m+1$ points $x_0, x_1, \cdots, x_m \in \mathbb{R}^n$ are affinely independent if the vectors $x_1 - x_0, x_2 - x_0, \cdots, x_m - x_0$ are linearly independent. Equivalently, the points are affinely independent if the only solution to the equation:

$$
\sum_{i=0}^m \theta_i x_i = 0, \quad \sum_{i=0}^m \theta_i = 0
$$
is $\theta_0 = \theta_1 = \cdots = \theta_m = 0$.

### Simplex

A simplex is the convex hull of a set of affinely independent points. In other words, if $x_0, x_1, \cdots, x_m \in \mathbb{R}^n$ are affinely independent, then the simplex generated by these points is:

$$
\text{conv}\{x_0, x_1, \cdots, x_m\} = \left\{\sum_{i=0}^m \theta_i x_i : \theta_i \geq 0, \sum_{i=0}^m \theta_i = 1\right\}.
$$

*Note*: $\mathbb{R}^n$ only has $m$-simplexes for $m \leq n$.

#### Unit $n$-simplex

The unit $n$-simplex is defined as:
$$
\Delta^n = \left\{x \in \mathbb{R}^{n+1} : x_i \geq 0, \sum_{i=0}^n x_i = 1\right\}.
$$

### Convex cone

#### Cone

A set $C$ is cone if for any $x \in C$ and $\theta \geq 0$, we have $\theta x \in C$.

A convex cone is a cone that is convex.

**Proposition**: A set $C$ is a convex cone if and only if for any $x_1, x_2 \in C$ and $\theta_1, \theta_2 \geq 0$, we have $\theta_1 x_1 + \theta_2 x_2 \in C$.

### Conic hull

The conic hull of a set $S \subset \mathbb{R}^n$, denoted as $\text{cone}(S)$, is the smallest convex cone containing $S$. It can be expressed as:
$$
\text{cone}(S) = \left\{\sum_{i=1}^m \theta_i x_i : x_i \in S, \theta_i \geq 0, m \in \mathbb{N}\right\}.
$$
