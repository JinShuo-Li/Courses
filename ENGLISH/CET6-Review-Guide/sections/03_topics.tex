\subsection{通用衔接与高分句式（写作）}

\begin{multicols}{2}
\textbf{开头段}
\begin{itemize}
  \item It is widely acknowledged that ...
  \item There is a growing awareness of the importance of ...
  \item Nowadays, an increasing number of people come to realize that ...
  \item When it comes to ..., opinions vary from person to person.
\end{itemize}

\textbf{主体段}
\begin{itemize}
  \item To begin with, ... In addition, ... Last but not least, ...
  \item A case in point is that ...
  \item Take ... as an example. / Another example is ...
  \item It is not hard to find that ...
  \item What deserves special attention is that ...
  \item Compared with ..., ... has more advantages.
\end{itemize}

\textbf{结尾段}
\begin{itemize}
  \item In conclusion / To sum up, ...
  \item Only when ... can we ...
  \item It is high time that we took effective measures to ...
  \item Therefore, it is of great significance for us to ...
\end{itemize}

\textbf{高级替换}
\begin{itemize}
  \item important $\to$ vital, crucial, essential, significant
  \item think $\to$ believe, maintain, hold the view that
  \item more and more $\to$ an increasing number of
  \item many $\to$ a host of, numerous, a considerable number of
  \item get $\to$ obtain, acquire, gain
  \item very $\to$ exceedingly, remarkably, highly
  \item in my opinion $\to$ from my perspective, as far as I am concerned
  \item cause $\to$ give rise to, lead to, result in, trigger
\end{itemize}
\end{multicols}
