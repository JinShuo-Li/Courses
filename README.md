# Courses

Undergraduate course materials for the IEEE Honor Program at Shanghai Jiao Tong University.

This repository collects my personal study materials — class notes, assignments, projects, and exam papers. Instructor slides, textbooks, and build artifacts are intentionally excluded to keep the repository lean.
